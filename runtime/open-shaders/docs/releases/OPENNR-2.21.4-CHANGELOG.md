# OpenNR 2.21.4

- Add per-eye X/Y alignment controls for projection-centred NR crops. A zero per-eye value preserves the existing shared-offset behavior.
- Add UI sliders and a reset control for Pimax and other headsets whose lens centres differ from Quest 3.
- Limit per-eye offsets to ±200 px.

No GPU timing, package validation, or in-game acceptance is included in this release candidate.
