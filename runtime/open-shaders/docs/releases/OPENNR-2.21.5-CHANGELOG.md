# OpenNR 2.21.5

## Neural Rendering settings

- Group route, whole-eye periphery, edge blend, colour and tone, adaptive, and diagnostics controls.
- Show the active Neural Rendering route, periphery refusal reason, display and render dimensions, and coverage.
- Add section resets, a Recommended preset that restores shipped defaults, and a Safe mode preset that disables Neural Rendering and whole-eye Periphery NR.
- Clarify the separate foveated stretched-periphery controls and NR whole-eye periphery controls.
- Remove the inactive guided-filter option from the interface and benchmark presets while retaining legacy settings-file compatibility.
- Keep the 2.21.4 rendering defaults and route decisions unchanged.
