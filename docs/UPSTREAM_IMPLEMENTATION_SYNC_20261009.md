## Combined Skylighting state machine

**[SOURCE-VERIFIED]** On startup/resource rebuild, game load, interior/exterior transition, interior cell change, or worldspace change, OpenNR resets probe SH to unit SH, accumulation/history state, directional visibility to lit, and occlusion depth to 1. Exterior directional shadow sampling is admitted only when its light, structured data, and two-slice shadow SRV exist. If those inputs disappear, consumers fail lit and new probe dispatches clear shadow history; on recovery the visibility/bits are reseeded before directional history is sampled again. The history is a seeded-lit 32-bit shift register, divided by 32 throughout warm-up. Interior sampling stays opt-in/off by default: when disabled, consumers return neutral lighting; when enabled, the separate occlusion-only path can update ambient probe SH while directional shadow visibility remains neutral. `ForceNeutralOutput` still overrides output without changing the probe resource/update state, and `[Skylighting-Dungeon]` diagnostics remain intact.

**[INFERENCE]** These upstream changes harden the same history/reset class implicated in the earlier dungeon-black investigation, but do not establish that all changes fix that exact user symptom. No live game or headset validation was performed by this stream.
